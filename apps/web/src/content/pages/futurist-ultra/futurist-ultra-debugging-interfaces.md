# Debugging & Power Interfaces

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Hardware Expansion Interface | Interface | Description |
| --- | --- | --- | --- |
| 1 | Maintenance bay: for debugging and secondary development (waist) | USB Type-A 2.0 | Supports ADU/MDU serial port reading and debugging |
| 2 | Maintenance bay: for debugging and secondary development (waist) | Ethernet | Supports ADU debugging and secondary development |
| 3 | Maintenance bay: power interface (waist) | USB Type-C | 5 V/3 A output; can charge external devices such as the remote controller |
| 4 | Maintenance bay: for debugging and secondary development (head) | USB Type-C | Supports debugging and secondary development of the head HDU (RK3588s); supports connecting a microphone receiver |
