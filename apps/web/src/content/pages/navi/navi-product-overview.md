# Product Overview

## Scope of This Manual

This manual covers the NAVI Series quadruped robot. It provides guidance on safe operation, product features, component identification, and basic setup.

## Terminology and Definitions

### NAVI
NAVI is the product name of an AI-powered quadruped robot.

### Large Language Model (LLM)
A large language model is an AI technology capable of understanding and generating human language. During intelligent voice interaction, it understands your voice input, generates relevant text output, and converts it into speech for interaction.

## Product Features and Main Functions

### Graphical Programming
Includes motion categories, with features continuously updated.
Program NAVI via the App to create more motion combinations.

### Multi-Function Remote Control
Supports App-based remote control and fingertip gamepad control.
