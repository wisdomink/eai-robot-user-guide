# Debugging & Power Interfaces

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Hardware Expansion Interface | Interface | Description |
| --- | --- | --- | --- |
| 1 | Maintenance bay: for debugging and secondary development | USB Type-A 2.0 (lumbar) | Supports MDU serial reading and debugging. |
| 2 | Maintenance bay: for debugging and secondary development | USB Type-C (head) | Supports head HDU (RK3588s) debugging and secondary development. Supports connecting a microphone receiver. |
| 3 | Power interface | USB Type-C | 5 V / 3 A output; can charge external devices such as the remote controller. |
