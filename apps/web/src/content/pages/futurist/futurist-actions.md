# Dance & Body Actions

## Full-body Dance

Select the dance content from the skill set and slide to play

### Step 1: Press the [Skills] the top tab bar

![FF All-New Futurist — Dance & Body Actions](/images/futurist/futurist-v32-62.png)

### Step 2: Select the desired dance, and slide to execute

> ❗ Note: Dances need to be confirmed and executed according to pop-up instructions. Follow the tips to ensure safety.

![FF All-New Futurist — Dance & Body Actions](/images/futurist/futurist-v32-63.png)

## Body Actions

From the skill set the user can select different actions to play.

### Upper-Limb Actions

On the client home page, tap Skills → Resource Management, then select an action to play.

![FF All-New Futurist — Dance & Body Actions](/images/futurist/futurist-v32-64.png)

### Upper-Limb Compliant Motion Playback (Passive Safety)

When this switch is turned on, the robot's arms become compliant, which reduces collision force.

![FF All-New Futurist — Dance & Body Actions](/images/futurist/futurist-v32-65.png)
