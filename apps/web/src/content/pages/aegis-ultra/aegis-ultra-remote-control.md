# Remote Control User Guide

## Remote Controller Introduction

![Remote controller](/images/aegis-ultra/aegis-ultra-remote-control-1.png)

1. Press and hold the power button at the top of the remote controller to power on.
2. Tap `Smart Robot Controller` to launch the application.

![Launch app](/images/aegis-ultra/aegis-ultra-remote-control-2.png)

3. The app main page will be displayed.

![App main page](/images/aegis-ultra/aegis-ultra-remote-control-3.png)

4. Tap the button in the upper left corner to enter System General Settings.

![General settings button](/images/aegis-ultra/aegis-ultra-remote-control-4.png)
![General settings page](/images/aegis-ultra/aegis-ultra-remote-control-5.png)

5. Tap `Not Connected` in the upper right corner to start remote controller connection.

![Not connected](/images/aegis-ultra/aegis-ultra-remote-control-6.png)

6. Select the Wi-Fi network of the robot to connect. The Wi-Fi name is found on the device nameplate.
    For a password, pleas enter **12345678**.

![Select Wi-Fi](/images/aegis-ultra/aegis-ultra-remote-control-7.png)

7. After successful connection, the app will confirm pairing.

![Connection successful](/images/aegis-ultra/aegis-ultra-remote-control-8.png)

## Operations Instructions

### Two operating modes: Normal Mode and Laboratory Mode

- Normal Mode: Stable movement and standard actions for daily use
- Laboratory Mode: Enhanced performance and additional special actions for research and demonstrations

| Function | Controller / App |
| --- | --- |
| Stand | App |
| Stand Damping (Slowly Lie Down) | App |
| Lie Down / Emergency Stop | `L1 + R1` or App |
| Forward / Backward / Left / Right | Controller |
| Pitch Adjustment | Push right joystick forward / backward |
| Horizontal Turn | Push right joystick left / right |
| Left / Right Head Tilt | `Y / A` |
| High / Low Posture | `X / B` |
| Special Actions | App in Laboratory Mode |

Warning:

Special actions in Rage / Laboratory Mode impose heavy loads on the joint modules. Use them cautiously and limit duration to protect device lifespan.

## Function Description

### Basic Control

1. Tap the control button in the lower right corner to enter the control page.

![Control entry](/images/aegis-ultra/aegis-ultra-remote-control-13.png)

2. Control the robot's movement and posture changes by tapping the center button, using the virtual joystick, or virtual buttons.

![Control page](/images/aegis-ultra/aegis-ultra-remote-control-14.png)

### Screen Recording

1. Tap the screen recording button to start recording.

![Start recording](/images/aegis-ultra/aegis-ultra-remote-control-15.png)

2. Tap the red stop button to end recording.

![Stop recording](/images/aegis-ultra/aegis-ultra-remote-control-16.png)

3. Recorded videos can be viewed in the remote controller gallery.

![Recording gallery](/images/aegis-ultra/aegis-ultra-remote-control-17.png)

### Screen Shot

1. Tap the screenshot button in the lower right corner.

![Take screenshot](/images/aegis-ultra/aegis-ultra-remote-control-18.png)

2. Screenshots can be viewed in the remote controller gallery.

![Screenshot gallery](/images/aegis-ultra/aegis-ultra-remote-control-19.png)

### Tracking Function

1. Tap the settings button in the upper left corner.

![Tracking settings entry](/images/aegis-ultra/aegis-ultra-remote-control-20.png)

2. Select the tracking function.

![Tracking menu](/images/aegis-ultra/aegis-ultra-remote-control-21.png)

3. Select a detected target and tap `Start Tracking`.

![Trackable targets](/images/aegis-ultra/aegis-ultra-remote-control-22.png)
![Start tracking](/images/aegis-ultra/aegis-ultra-remote-control-23.png)

### Video Stream Toggle

1. Tap the settings button in the upper left corner.

![Video stream settings entry](/images/aegis-ultra/aegis-ultra-remote-control-24.png)

2. Select the video stream toggle and save the settings.

![Video stream toggle](/images/aegis-ultra/aegis-ultra-remote-control-25.png)
