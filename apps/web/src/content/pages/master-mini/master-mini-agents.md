# Using Agents

## What Is an Agent?

An Agent is a "skill pack" installed in the robot's brain. It can also be understood as an application running on the robot. Like switching apps on a phone, switching Agents lets the robot enter the corresponding capability scenario and use different interaction methods and task capabilities.

## How to Switch Agents

## Switch via the Mobile App

Tap the Agent name in the top-left corner to switch to another Agent. Each Agent has different capabilities — for example, Soccer Master can play soccer with you, Hi Chat can talk with you using different personas, and Dance Master can perform a variety of dances from around the world.
