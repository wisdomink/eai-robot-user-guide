# Remote Support

## Introduction

When the robot has issues and you need remote assistance, follow these steps to get remote support from our staff.

## Information to Send to Technical Support

- Device ID and one-time password.

- The robot's current status: whether it can power on, whether it can connect to the network, and its current mode.

- Symptoms: for example, unable to walk, abnormal App connection, upgrade failure, etc.

- The time the issue occurred and the operation you were performing at the time.

- Whether logs have been uploaded, or exported by yourself via terminal.

## Remote Assistance Procedure

You can choose from the following two remote assistance methods:

Connect your personal computer to the robot via SSH; technical support can then connect to your computer via remote desktop and subsequently to the robot via SSH.

Install remote desktop software on the robot; you can use a display and keyboard/mouse to open the remote desktop software, allowing support personnel to connect directly to the robot.
