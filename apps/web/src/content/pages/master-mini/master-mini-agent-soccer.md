# Soccer Agent

Designed for soccer scenarios. It can autonomously track, chase, kick, and shoot the ball, and can accurately reproduce signature celebration moves from soccer stars such as Cristiano Ronaldo and Messi.

### Functions

| Functions | Master Mini joystick buttons | Xbox joystick buttons | Prerequisites |
| --- | --- | --- | --- |
| Shake Hand | A | A | Under WALK mode |
| Wave | B | B | Under WALK mode |
| Get Up | L2 + UP | LT + UP | Under DAMP/PREP mode |
| Track Ball | L2 + A | LT + A | Under WALK mode |
| Chase Ball | L2 + B | LT + B | Under WALK mode |
| Kick Ball | L2 + X | LT + X | Under WALK mode |
| Power Kick | L2 + Y | LT + Y | Under WALK mode |
| Siuuu | L + Y | LB + Y | Under WALK mode |
| Arms Crossed | L + B | LB + B | Under WALK mode |
| Point to Sky | L + UP | LB + UP | Under WALK mode |
| Cradle Dance | L + DOWN | LB + DOWN | Under WALK mode |
