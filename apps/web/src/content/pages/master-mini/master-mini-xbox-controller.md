# Xbox Controller

Use a standard Xbox joystick. Before use, confirm that the joystick control mode is receiver mode and that the operating mode shows three lights steadily on.

## Basic Capabilities

| --- | --- | --- |
| Enter Master Mini Agent | LT + RT + A |  |
| Enter Soccer Agent | LT + RT + B |  |
| Enter Hi Chat Agent | LT + RT + X |  |
| Enter Dance Agent | LT + RT + Y |  |
| Enter Lion Dance Agent | LT + RT + UP |  |
| Enter DAMP mode | LT + Back |  |
| Enter PREP mode | LT + Start |  |
| Enter WALK mode | RT + A | Under PREP mode |
| locomotion control | Left stick | Under WALK mode |
| rotation control | Right stick | Under WALK mode |
| head rotation | Direction buttons | Under WALK mode |
