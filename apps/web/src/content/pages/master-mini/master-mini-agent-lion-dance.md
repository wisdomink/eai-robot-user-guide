# Lion Dance Agent

> **Controller difference:** The source’s Xbox controller table additionally lists **Lion Dance 3 — LB + UP**, in WALK mode. The Lion Dance Agent table lists only Lion Dance 1 and 2; check your software version before using the additional mapping.

Focused on traditional folk performance, skillfully performing authentic Southern-style lion dance and showcasing the charm of traditional Chinese culture.
