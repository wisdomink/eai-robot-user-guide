# Restarting Services

> **Terminal command unavailable:** The supplied manual refers to service restart commands but does not provide them. Use the documented App procedure or obtain the correct commands from technical support. Support the robot before restarting its services.

## Use the App

On the control page, tap "Settings" to enter the settings page.

On the settings page, tap "Restart Robot" to restart the robot.

## Use a Terminal

Use another device to connect to the robot through a terminal

The source refers to service commands that can be run in any directory on the robot, but the commands are not included.

💡 Note: restarting the robot service fully restarts the robot firmware. Make sure the robot is properly supported on a stand or lying flat on the ground before doing this.
