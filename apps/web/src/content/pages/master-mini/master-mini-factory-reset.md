# Factory Recovery

> **Recovery command unavailable:** The source describes a recovery directory and program but does not provide their path or command. Obtain the device-specific recovery procedure from technical support before proceeding.

## Restore Factory Settings

When FF Master Mini cannot return to a usable state due to configuration changes, software errors, or environment changes, you can restore factory settings to reinstall the factory software.

### When to Use

- Abnormal behavior after modifying the robot's configuration, which cannot be recovered through normal configuration rollback.

- Technical support recommends reinstalling the factory software to rule out environment issues.

- You need to restore the robot to a software state close to its initial delivery.

### Before You Begin

Restoring factory settings may erase existing configurations and local changes. Before proceeding, back up important configurations, logs, and custom files, and make sure the robot is in a stable, well-supported state.

- Confirm that the current robot model and the recovery package are compatible with FF Master Mini.

- Make sure the power, network, and terminal connection are stable, and do not cut off power during the recovery process.

- If you are not sure whether a recovery is needed, contact technical support first.

### Perform the Recovery

After logging in to the robot's board, navigate to the recovery directory and run the recovery program. The source does not include the recovery command. If there are multiple packages in the recovery directory, use the file that matches your device version after confirming the procedure with technical support.

### After the Recovery

1. Wait for the recovery program to finish, and restart the robot as prompted.

2. Confirm that the robot starts normally and that basic services and network connection are restored.

3. Reconfigure the network, App, voice, or custom parameters that you want to keep.

4. If the robot still behaves abnormally after recovery, record the symptoms and provide logs to technical support as described on the "Log Retrieval" page.
