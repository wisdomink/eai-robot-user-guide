# Controller & Settings

After starting the APP, you will automatically enter the control interface, as shown in the figure below:

![Controller status and system controls](/images/aegis-mega-d/aegis-mega-d-18.png)

## Status and System Controls

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ① | Controller Power | Press and hold to power on/off, and press once to wake |
| ② | STOP | Trigger the soft emergency stop and force the robot to lie down. Typically used when the robot is out of control or in emergency situations |
| ③ | Control Mode | Press to switch control modes: Regular / Navigation / Assist |
| ④ | Settings | Settings: About Device / Sensor / Status / Accessibility & Convenience |
| ⑤ | LiDAR | Indicates that the dual LiDAR is enabled. To enable this function, go to ‘Settings – Sensor Management’ |
| ⑥ | Robot Signal | Visible only when the controller is connected to the robot, showing connection signal strength and latency information |
| ⑦ | STOP | Soft Emergency Stop |
| ⑧ | Expand / Close | Press to expand / close robot dashboard |
| ⑨ | Remaining | Estimated Remaining Operating Range |
| ⑩ | Battery Information | Left and right values indicate the remaining battery percentage of the front and rear sides |

</div>

![Movement, gait and camera controls](/images/aegis-mega-d/aegis-mega-d-19.png)

## Movement and Camera Controls

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ⑪ | Sit/Stand | Stand up or sit down, and the button displays the current status |
| ⑫ | Left Joystick | Control the robot to translate |
| ⑬ | Right Joystick | Control the robot to rotate |
| ⑭ | Speed Adjustment | Press the gear icon to enable speed adjustment. Slide the slider to set the maximum speed |
| ⑮ | Change Direction | Press to switch movement direction: Forward / Reverse. The current state is highlighted in blue |
| ⑯ | Gait | Press on the gait name to switch gait. The gait displayed in blue is the current gait |
| ⑰ | Camera | Press to switch the number of camera video streams: Single-View / Dual-View |
| ⑱ | Camera View | Press to switch the camera video streams displayed on the main interface: Front View / Rear View |
| ⑲ | Flashlight | Press to control the lighting mode: Flashlight OFF / Front Flashlight / Rear Flashlight / All Flashlights |
| ⑳ | Photo | Save images from the video streaming |
| ㉑ | Video | Record a video of the video streaming |

</div>

![Joint dashboard and shoulder buttons](/images/aegis-mega-d/aegis-mega-d-20.png)

## Joint Dashboard and Shoulder Buttons

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ㉒ | Joint Temperature | After pressing, the switch will be highlighted in blue and the joint temperature panel will be displayed |
| ㉓ | Charge | After pressing, the robot automatically switches to navigation mode and executes autonomous charging tasks |
| ㉔ | Joint Parameters | After pressing, the switch will be highlighted in blue and the joint parameters panel will be displayed |
| ㉕ | Joint Temperature Panel | Display joint temperature information. Press on the motor/driver to switch to view the joint module temperature. Warn/Error of the motor/driver is displayed in orange/red respectively |
| ㉖ | Joint Parameters Panel | Display joint movement parameter information |
| ㉗ | L1 | Make the robot stand up or lie down, same as button ⑪ |
| ㉘ | L2 | Switch main screen camera view, same as button ⑲ |
| ㉙ | R1 | Shortcut key, set it in “Settings – Accessibility – Shortcut Key” |
| ㉚ | R2 | Shortcut key, set it in “Settings – Accessibility – Shortcut Key” |

</div>

## Setting Operation

After starting the APP, press the [④ Settings] button to enter the settings interface, as shown in the figure below:

![Settings interface](/images/aegis-mega-d/aegis-mega-d-21.png)

## Settings Reference

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ① | About Device | View: Serial Number / Model / System Version / APP Version, and perform OTA |
| ② | Sensor | Can enable or disable: LiDARs / Wide Angle Cameras |
| ③ | Status | View: Motion / Posture / CPU / Battery status |
| ④ | Accessibility | Set: WiFi / Shortcut Key / Language |

</div>


**L2 reference:** The source describes L2 as switching the main camera view but refers to button ⑲, which its button table identifies as the flashlight. Confirm the L2 mapping on the controller; the source reference is retained above.
