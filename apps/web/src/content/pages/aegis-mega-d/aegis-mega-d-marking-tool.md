# Route Marking Tool

## Enabling the Marking Tool

Press [④ Accessibility] button on the control page to open the route list panel.

![Enable the marking tool](/images/aegis-mega-d/aegis-mega-d-22.png)

## Marking Tool Operation

After starting the APP, press [① Marking Tool] button to enter the route list interface as shown below:

![Route list controls](/images/aegis-mega-d/aegis-mega-d-23.png)

## Route List Controls

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ① | Marking Tool | Press to enter the route list interface. |
| ② | Edit/Delete | Press to edit/delete a route. |
| ③ | LoopCount | Press to set the number of times the robot repeats a single route. |
| ④ | Start | Press to start executing the route; press again during execution to stop. |
| ⑤ | Add | Press to add a new route at the end of the route list. |
| ⑥ | Save | Press to save the current route list. |

</div>

## Edit a Route

After pressing [Edit Route] or [Add Route], enter the route settings page.

![Route editing controls](/images/aegis-mega-d/aegis-mega-d-24.png)

## Route Editing Controls

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ⑦ | Edit/Delete | Press to edit/delete a waypoint. |
| ⑧ | Add | Press to add a waypoint at the end of the list. |
| ⑨ | Insert | Press to insert a waypoint before the currently selected waypoint. |
| ⑩ | Save | Press to save the current route. |

</div>

## Add or Insert a Waypoint

After pressing [⑧ Add Waypoint] or [⑨ Insert Waypoint], enter the add waypoint settings page.

![Waypoint settings](/images/aegis-mega-d/aegis-mega-d-25.png)

## Waypoint Controls

<div class="overflow-x-auto" role="region" aria-label="Scrollable table" tabindex="0">

| No. | Name | Function |
| --- | --- | --- |
| ⑪ | Refresh Location | Press to get current coordinates: the bar below turns green on success, red on failure. |
| ⑫ | Switch Map | Press to modify the map ID. |
| ⑬ | PointType | Press to switch waypoint type: Transition / Task / Charge; highlighted item is the selected type. |
| ⑭ | Gait | Press to switch gait type: Basic / Stair; highlighted item is the selected type. |
| ⑮ | NavMode | Press to switch navigation mode: Straight / Autonomous; highlighted item is the selected mode. |
| ⑯ | Speed | Press to switch movement speed: Low / Normal / High; highlighted item is the selected speed. |
| ⑰ | Direction | Press to switch movement direction: Move Forward / Move Backward; highlighted item is the selected direction. |
| ⑱ | Obstacle Detection | Press to enable/disable obstacle detection; the button is highlighted in blue when enabled. |
| ⑲ | Cancel | Press to cancel the current waypoint setting operation. |
| ⑳ | Save | Press to save the current waypoint settings. |

</div>
