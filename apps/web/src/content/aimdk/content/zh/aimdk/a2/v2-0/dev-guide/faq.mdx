# 11. 常见问题解答

## 11.1 什么是机上软件版本？

A2 机器人出厂时会自带一系列机上软件，这些软件会随着版本 OTA 升级而升级。

一般在 ssh 连接到机器人上时会打印出软件版本（当前应用版本），也可通过 AimMaster 软件进行查看，一般为 1.2.x 这种形式的版本号。

## 11.2 什么是 P1，什么是 T3？

P1 和 T3 是 A2 机器人的硬件型号，硬件型号不同主要的区别就在于工控机配置不同，例如网卡配置、硬件连接等，但是上层接口基本是统一的。

ssh 登录上 x86 工控机后可以通过查看 /etc/bsp\_version 来确认是什么版本，有此文件则为 P1，无此文件则为 T3。

## 11.3 手臂关节电机上报超速异常，如何处理？

![](https://open.agibot.com/docs/_image?href=%2Fdocs%2F_astro%2FAsQTtyVv.png&w=2112&h=256&f=webp)

原因：调用手臂接口时，传入的位置和当前位置存在一定阶跃，导致电机过速引发限流，此时嵌入式底层会对关节进行失能保护，并同步上报告警。

解决办法：一般情况下重启机器人即可恢复，为避免此问题，调用手臂 ROS2 Topic 接口时，请将关节位置进行滤波和平滑后传入，确保传入值与当前状态不存在较大阶跃。

## 11.4 是否支持自行开发运动控制程序？

默认情况下不开放下肢关节电机的底层控制接口，仅能通过高层速度指令进行整体控制，如需自行开发运动控制算法替换智元出厂自带算法，请参考文档中的 A2 旗舰款底层运控开发指南。替换前请务必阅读运控开发风险提示与安全注意事项。
