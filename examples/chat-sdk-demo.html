FFRobot Chat SDK Hosted Script Demo

这个页面用于模拟一个全新的外部页面，通过发布后的脚本直接接入聊天面板。 当前示例引用线上 SDK，并使用 SDK 内置的生产默认配置： https://robotics-instruction-manual.ff.com/dist-embed/ffrobot-chat-sdk.js。

This page simulates a fresh third-party site that loads the published embed script to attach the chat panel. The example pulls the hosted SDK and relies on its built-in production defaults: https://robotics-instruction-manual.ff.com/dist-embed/ffrobot-chat-sdk.js.

使用说明 Usage (English)

请不要直接用 file:// 打开本页。请先在html文件所在目录启动静态服务： python3 -m http.server 8080

Do not open this file via file://. From the directory that contains this HTML file, start a static server, for example: python3 -m http.server 8080

服务启动后，请通过以下链接访问本页： http://127.0.0.1:8080/chat-sdk-demo.html

Then open this demo at: http://127.0.0.1:8080/chat-sdk-demo.html

如果控制台出现 Origin not allowed，说明当前页面域名不在发布版 SDK 对应的允许列表中，不能用这个 origin 直接接入。

If the browser console shows Origin not allowed, the current page origin is not on the allowlist for the published SDK build, so you cannot embed from that origin.
