AI 助手 Chat 请求流程

User → Triage Agent → Support Agent → Recommendation Card

Phase 0 · 用户输入
💬 用户发送消息
ChatKit 前端接收用户输入，调用后端 respond()
📜 加载会话历史
从 InMemoryStore 读取当前 thread 的所有历史消息，构建完整上下文
Phase 1 · Triage 预处理（非流式）
📋 读取推荐规则 recommendations.json
RecommendationEngine.build_triage_rules_prompt() 读取所有 enabled=true 的推荐规则，生成规则 prompt 片段
🔧 动态构建 Triage Agent triage.md
将规则注入 triage.md 模板的 {{recommendation_rules}} 占位符，创建本次请求专用的 Triage Agent
🧠 Triage Agent 执行
调用 Runner.run() 执行结构化分析，输出 TriageOutput：
input_lang query_scope query_type query_text purchase_intent recommendation_hit recommendation_rule_id
Phase 2 · Support Agent 回答（流式）
🔀 路由到产品 Agent
根据 query_type 路由：master-ultra / futurist-ultra / aegis-ultra / aegis-edu / ff91 / general / out-of-scope
🔍 构建 Support Agent + FileSearch
将 input_lang 和扩写后的 query_text 注入指令模板，绑定对应产品的 Vector Store 进行 RAG 检索
📡 流式回答
Runner.run_streamed() 流式输出回答，同时重写图片 URL 和调整 citation 位置索引
Phase 3 · 推荐判定
🎯 评估推荐结果
evaluate_post_answer() 根据 Triage 输出的 recommendation_rule_id 查找匹配的推荐规则，检查是否已在此 thread 中展示过
✓ 命中推荐
根据 input_lang 选择中/英文推荐文案，生成产品推荐图鉴卡片追加到回答后
✗ 未命中 / 已展示
不追加推荐内容，回答流正常结束
Phase 4 · 最终输出
✅ 响应完成
用户看到：主回答（含引用来源链接）+ 可能的推荐图鉴卡片（产品标题 + 推荐文案）
用户输入 & 上下文
Triage 预处理（非流式）
Support Agent（流式 RAG）
推荐判定
最终输出
