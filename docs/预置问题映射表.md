## 实现说明

- 前端根据 `window.location.pathname` 匹配路径，精确匹配优先，前缀匹配次之，无匹配使用 Fallback
- 欢迎语和预置问题在聊天窗口首次打开时展示，用户发送消息或点击问题后收起
- 点击预置问题时，应将当前页面上下文（产品型号）一并传给 AI，提升 RAG 检索精准度
- 切换页面时（SPA），若聊天窗口未打开则更新预置问题；若已有对话则保持当前对话不打断
