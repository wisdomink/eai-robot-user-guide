## FF 91 2.0 Futurist

**路径：** `/product/ff-91-Futurist`

### 2.1 FF 91 2.0 的续航和充电时间？

FF 91 2.0 搭载 **142.3 kWh** 高压电池，续航和充电时间会随电量状态、充电桩功率和环境条件变化。

**续航方面**
- 仪表续航显示分为几个提醒区间：
 - **超过 50 miles（80 km）**：正常显示
 - **50–11 miles（80–18 km）**：提示尽快充电
 - **10 miles（16 km）及以下**：提示立即停车充电
- 当电量低于约 **20%** 时，仪表会转为警示状态，车辆性能会受限，以延长续航。

**充电时间方面**
- **AC 交流充电**：最大充电能力为 **15.3 kW**，要达到这个速度需要 **240V / 64A** 电源。
- **DC 直流快充**：最高可达 **185 kW**，通常在 **80% SOC 以下** 充得最快；超过 **80%** 后会逐步降速。
- 便携充电线大致功率：
 - **110V / 15A：1.65 kW**
 - **110V / 20A：2.20 kW**
 - **240V / 40A：9.60 kW**

如果您想，我可以继续帮您按“家用慢充 / 公共快充”分别估算大概充满要多久。

### 2.2 支持哪些智能驾驶功能？

FF 91 2.0 支持的智能驾驶/驾驶辅助功能主要有这些：

| 功能 | 作用 |
|---|---|
| **AEB 自动紧急制动** | 识别前方潜在碰撞风险，必要时自动制动，减轻碰撞影响 |
| **FCW 前向碰撞预警** | 检测到潜在碰撞场景时发出声光提醒 |
| **LDW 车道偏离警告** | 车辆无意偏离车道线时提醒您 |
| **LKA 车道保持辅助** | 在车道内行驶时提供转向修正，帮助保持车道 |
| **TSR 交通标志识别** | 识别限速、禁止超车等道路标志并显示在仪表盘 |
| **ACC 自适应巡航控制** | 设定巡航速度后，可自动跟车并保持车距，前车减速至停下时车辆也可停住 |
| **BSM 盲区监测** | 监测侧后方盲区，提醒并线风险 |
| **Rear View Monitoring 倒车后方来车监测** | 倒车时检查后方横向来车或移动目标物并发出提示 |
| **High Beam Auto-Dimming 远光灯自动切换** | 根据环境和来车灯光自动切换远近光 |

补充一点：这些功能都是**驾驶辅助**，不是替代驾驶员操作的自动驾驶系统。驾驶时车辆控制与安全仍由您负责。

如果您愿意，我也可以继续帮您把这些功能按“高速行驶 / 变道 / 停车”场景整理成更直观的版本。

### 2.3 1050 马力的动力系统是怎样的？
