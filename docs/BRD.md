# FF 官网智能客服系统 — Business Requirements Document

> 版本：v0.1 · 日期：2026-03-23 · 作者：Hai Zhang

---

## 1. 项目背景

FF 目前官网缺乏统一的智能客服入口，用户咨询依赖 400 电话和人工客服，存在以下痛点：

- **响应效率低**：非工作时间无法及时响应用户咨询
- **业务覆盖不全**：FF 业务横跨汽车（FF/FX）、EAI 机器人、AIxCrypto（AIxC）三大板块，现有客服无法统一支撑
- **缺乏自助服务**：用户无法在官网自主查询订单、预约试驾、了解产品参数等
- **数据沉淀缺失**：用户咨询数据未被系统化采集，无法反哺产品和运营决策

头部车企（特斯拉、理想、小米）已在官网部署智能客服，FF 需补齐这一能力。

## 2. 业务目标

| 目标 | 衡量指标 | 目标值 |
| --- | --- | --- |
| 提供全天候服务 | 服务可用时长 | 7×24 小时 |
| 提升响应速度 | 核心问题首次响应时间 | ≤1 分钟 |
| 降低人工客服压力 | AI 独立解决率 | ≥80% |
| 覆盖全业务线 | 业务覆盖范围 | 汽车、机器人、AIxC |
| 提升用户满意度 | CSAT 评分 | 待定（上线后基线测量） |
| 沉淀用户洞察 | 咨询数据可分析率 | 100% 结构化存储 |

## 3. 业务范围

### 3.1 服务对象

| 用户群体 | 说明 |
| --- | --- |
| C 端 — 潜在购车用户 | 了解车型、价格、预约试驾 |
| C 端 — 车主 | 用车指导、保养预约、故障咨询、售后服务 |
| C 端 — 机器人用户 | 产品了解、预订、使用咨询 |
| C 端 — AIxC 关注者 | 生态介绍、业务流程了解 |
| B 端 — 经销商/企业客户 | 批量采购咨询、定制化方案 |

### 3.2 业务覆盖场景

**汽车业务（FF 91 / FX 系列）**
- 车型参数、配置对比、价格咨询
- 购车流程、订单查询、交付进度
- 试驾预约
- 充电（家充安装、超充站查询）
- 保养预约、质保政策、售后服务
- 车辆操作指导（功能使用、故障排查）
- 金融方案（贷款、分期）

**EAI 机器人业务**
- 产品系列介绍、价格、预订流程
- 应用场景咨询（商业/工业/家庭）
- 企业定制化方案咨询入口

**AIxC 业务（合规范围内）**
- 公开生态介绍、业务流程说明
- 合规信息指引
- 商务对接入口
- **不提供**：投资建议、收益承诺、交易引导

**通用服务**
- 官网预约（试驾、机器人体验、商务对接）
- 联系方式查询（400 电话、服务中心）
- 人工客服转接

### 3.3 明确不做的事

- 生活类问答（天气、新闻、娱乐、外卖等）
- 非 FF 产品咨询
- 未发布产品/内部信息泄露
- 投资建议、交易引导
- 竞品贬低性言论
- 通用 AI 聊天（非专用场景）

## 5. 核心业务需求

### BR-1：多业务统一咨询入口
用户通过一个入口即可咨询汽车、机器人、AIxC 全线业务，无需跳转不同页面或拨打不同电话。

### BR-2：7×24 小时自助服务
AI 客服全天候在线，能独立回答产品参数、购车流程、订单查询等高频问题，减少对人工客服的依赖。

### BR-3：智能人工转接
AI 无法解决的问题，按业务类型转接对应的人工坐席；非工作时间支持留资回拨（姓名、电话、城市）。

### BR-4：知识库全覆盖
基于 FF 官方信息构建专属知识库，覆盖汽车全生命周期、机器人产品线、AIxC 合规公开信息，确保回答准确专业。

### BR-5：跨业务上下文保持
用户在同一会话中切换业务咨询时，系统保留上下文，无需重复提供背景信息。

### BR-6：合规与风控
AIxC 相关回答严格限于公开合规信息，不提供投资建议；所有回答不贬低竞品；用户数据加密存储，符合隐私法规。

### BR-7：用户反馈机制
支持用户对回答进行评价（有用/无用），数据用于持续优化知识库和回答质量。

### BR-8：数据沉淀与分析
结构化记录所有咨询数据（问题分类、解决率、热点问题、用户画像），为产品优化和商业决策提供支撑。

## 6. 终端覆盖

- PC 端官网（ff.com / faradayfuturecn.com）
- 移动端官网（响应式适配）

## 7. 风险与约束

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| AIxC 合规风险 | 回答涉及金融信息可能引发法律问题 | 所有 AIxC 话术经法务审核，设置合规提示固定话术 |
| 知识库准确性 | 错误信息损害品牌信任 | 知识库内容由业务部门审核后上线，定期更新 |
| 服务中断 | 系统故障导致用户无法获得帮助 | 故障时自动展示 400 电话等备用联系方式 |
| 用户隐私 | 咨询记录含个人信息 | 加密存储，符合《个人信息保护法》，仅用于服务优化 |
