# 感知模块

感知模块（Perception）负责机器人的环境感知功能，包括目标检测、6D位姿估计、多尺度对象处理和环境对象信息管理等功能。

本模块位于 orin 开发板上，http 后端监听的端口为 58001。

## 使用示例

提供 Http Curl 示例，需要将 127.0.0.1 替换为机器人 orin 开发板的 IP 地址：

### 2D目标检测

Terminal window

```
curl --location --request POST 'http://127.0.0.1:58001/rpc/aimdk.protocol.Object2dDetectionService/Get2dDection' \--header 'Content-Type: application/json' \--data-raw '{"header":{},"target_type":"TargetType_PLASTIC_BOX"}'
```

### 6D位姿估计

Terminal window

```
curl --location --request POST 'http://127.0.0.1:58001/rpc/aimdk.protocol.Object6dPoseEstimationService/Get6dPose' \--header 'Content-Type: application/json' \--data-raw '{"header":{},"target_type":"TargetType_METAL_SHELF"}'
```

### 更新操作的抓取对象

Terminal window

```
curl --location --request POST 'http://127.0.0.1:58001/rpc/aimdk.protocol.GraspObjService/UpdateGraspObjectsRequest' \--header 'Content-Type: application/json' \--data-raw '{"header":{},"objects":[{"id":"obj_001","dims":{"x":1.2, "y":0.8, "z":0.6},"pose":{"position": {"x":1.2, "y":0.8, "z":0.6}, "orientation":{"x":0.15, "y":0.86, "z":0.652, "w":1.234}},"frame_id":"right_arm_01"}]}'
```
