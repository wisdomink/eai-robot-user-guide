### 7.3.3 播放表情 RPC 接口

| 接口名 | `pb:/aimdk.protocol.RcEmoticonPlayerService/PlayerEmoticon` |
| --- | --- |
| 功能概述 | 播放指定 id 表情 |
| 接口类型 | HTTP JSON RPC |
| URL | http://192.168.100.100:59001/rpc/aimdk.protocol.RcEmoticonPlayerService/PlayerEmoticon |
| 入参 | 
```json
{
  "emoticon_id": "1"
}
```

-   emoticon\_id: 表情 id，需要先通过 GetEmoticon 接口获取可用 id

 |
| 出参 | 

```json
{
  "state": "CommonState_UNKNOWN"
}
```

-   state: 调用请求状态

 |
| 示例脚本 | examples/rc/a2\_PlayerEmoticon.sh |
| 备注 |  |
