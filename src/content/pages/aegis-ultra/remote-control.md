# Remote Control User Guide

## Remote Controller Introduction
![Controller power on](/images/aegis-ultra/rc-intro-1.png)

1. Press and hold the power button at the top of the remote controller to power on. 
2. Tap "Smart Robot Controller" to launch the application.
![Smart Robot Controller app](/images/aegis-ultra/rc-intro-2.png)

3. The APP main page will be displayed.
![APP main page](/images/aegis-ultra/rc-intro-3.png)

4. Tap the button in the upper left corner to enter System General Settings.
![System settings](/images/aegis-ultra/rc-intro-4.png)
![Connection screen](/images/aegis-ultra/rc-intro-5.png)

5. Tap "Not Connected" in the upper right corner to start the remote controller connection. 
![WiFi selection](/images/aegis-ultra/rc-intro-6.png)

6. Select the WiFi network of the robot dog to connect. The WiFi name is found on thedevice nameplate (format: "XGO13BW001").
![WiFi connected](/images/aegis-ultra/rc-intro-7.png)

7. Connection successful — the APP will confirm pairing. 
![Connection successful](/images/aegis-ultra/rc-intro-8.png)


## Operations Instructions
Two operating modes: Normal Mode & Laboratory Mode

Normal Mode: Stable movement, standard actions — daily use. 
Laboratory Mode: Enhanced performance and unlock addition special actions —— research use and demonstration scenarios.

| Category | Action | Normal Mode | Lab Mode |
| --- | --- | --- | --- |
| Normal/laboratory mode switch | | APP | APP |
| General Actions | Stand | APP | APP |
| | Stand Damping (Slowly Lie Down) | APP | APP |
| | Lie Down / Emergency Stop | L1+R1 or APP | L1+R1 or APP |
| Movement actions | Forward / Backward / Left / Right | Left Stick | Left Stick |
| In-place Actions | Idle/Moving Switch | APP | APP |
| | Pitch Adjustment | Push Right Joystick Fwd/Back | Push Right Joystick Fwd/Back |
| | Horizontal Turn | Push Right Joystick L/R | Push Right Joystick L/R |
| | Left/Right Head Tilt | Y/A | Y/A |
| | High / Low Posture | X/B | X/B |
| Special Actions | Jump Up | — | APP |
| | Forward Jump | — | APP |
| | Backflip | — | APP |
| | Waving Greeting | — | APP |
| | Biped Standing | — | APP |

**Warning:**
Special actions in Rage Mode may affect the device lifespan.
Performing special actions in Laboratory Mode imposes heavy loads on the joint modules. Prolonged operation may cause accelerated joint wear and significantly reduce service life.
Please enable with caution and reasonably control the duration of use to ensure long-term stability of the device. 
 
## Enable Laboratory Mode.
1. Tap the settings button in the upper left. 
![Lab mode step 1](/images/aegis-ultra/rc-lab-mode-1.png)

2. Enable Laboratory Mode. 
![Lab mode step 2](/images/aegis-ultra/rc-lab-mode-2.png)

3. A Laboratory Mode activation prompt will appear. If confirmed, tap “Confirm” to enable.
![Lab mode confirm](/images/aegis-ultra/rc-lab-mode-3.png)

4. Laboratory Mode Enabled.
![Lab mode enabled](/images/aegis-ultra/rc-lab-mode-4.png)

## Function description
**Basic Control**
a. Tap the control button in the lower right corner to enter control page.
![Basic control entry](/images/aegis-ultra/rc-functions-1.png)

b. You can control the robot dog’s movement and posture changes by tapping the center button on the screen, using the virtual joystick, or virtual buttons.
![Control page](/images/aegis-ultra/rc-functions-2.png)

**Screen Recording**
a. Tap the screen recording button in the lower right corner of the screen to start recording.
![Screen recording start](/images/aegis-ultra/screen-recording-1.png)

b. Recording in progress. Tap the red stop button to end recording.
![Screen recording stop](/images/aegis-ultra/screen-recording-2.png)

c. Recorded videos can be viewed in remote controller’s gallery.
![Screen recording viewed](/images/aegis-ultra/screen-recording-3.png)

**Screen Shot**
a. Tap the screen recording button in the lower right corner to take a screenshot.
![Screen Shot start](/images/aegis-ultra/screen-shot-1.png)

b. Screenshots can be viewed in the remote controller’s galley
![Screen Shot viewed](/images/aegis-ultra/screen-shot-2.png)

**Tracking Function**
a. Tap the settings button in the upper left corner.
![Tracking Function step 1](/images/aegis-ultra/tracking-function-1.png)

b. Select the tracking function.
![Tracking Function step 2](/images/aegis-ultra/tracking-function-1.png)

c. Red boxes identify all trackable targets. Tap to select a target, then tap “Start Tracking” to activate the tracking function. (once activated, tracking will continue. To avoid accidently targeting unintended objects, cancel tracking in time.)
![Tracking Function start](/images/aegis-ultra/tracking-function-3.png)

![Tracking Function stop](/images/aegis-ultra/tracking-function-3.png)


**Video Stream Toggle**
a. Tap the settings button in the upper left corner.
![Video Stream step 1](/images/aegis-ultra/video-stream-toggle-1.png)

b. Select the Video Stream toggle and save the settings.
![Video Stream step 2](/images/aegis-ultra/video-stream-toggle-1.png)
